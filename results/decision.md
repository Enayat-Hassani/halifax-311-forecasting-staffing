# Decision layer

Generated by `src/decide.py` from the forecasts of `results/baselines.md`: 52 weekly origins, open intervals only. Each forecast is turned into the integer agent requirement per half-hour and compared with the requirement of actual demand. Agent-hours are per week; one agent for one half-hour is 0.5 agent-hours. These are counterfactual requirements, not rosters and not HRM costs.

| Input | Value | Source |
|---|---|---|
| Service time | 237 s | Mean talk time, primary training (data) |
| Service level | 80% in 25 s | HRM documents; no current target published (assumption) |
| Patience | 120 s | Not identifiable from the data (assumption) |
| Queue model | Erlang A | Abandonment is recorded (choice) |
| Cost ratio r = c_u / c_o | 0.25 to 16 | Swept, not estimated (assumption) |

## Cost-ratio sweep

Each run is staffed three ways at each ratio. Point: the point forecast. Uplift: the point forecast times the q-quantile of actual / forecast over all open slots, q = r / (1 + r). Quantile: the same, by slot type (weekday or weekend, peak or off-peak). Both are fitted on 26 weekly origins from 2025-02-24 to 2025-08-18, inside training.
